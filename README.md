# 🚀 AI Interview Coach

AI Interview Coach is an intelligent interview preparation web app that simulates real interview scenarios and helps users improve their performance using AI-powered feedback.

---

## 📌 Features

* 📄 Upload Resume & Job Description
* 🤖 AI-generated interview questions based on skills & experience
* 🎤 Voice-based answer recording
* 📷 Live interview simulation with camera support
* 🧠 AI evaluation of answers
* 📊 Scoring for:

  * Technical Skills
  * Communication
  * Confidence
* 💬 Instant feedback & improvement suggestions

---

## 🛠️ Tech Stack

* Python
* Streamlit
* FAISS (RAG System)
* Groq AI
* SpeechRecognition
* streamlit-webrtc
* dotenv

---

## ⚙️ How It Works

1. Upload your resume
2. Enter job description
3. AI extracts skills & context
4. Generates interview questions
5. User answers via voice or text
6. AI evaluates response and gives scores + feedback
7. Next question is shown
